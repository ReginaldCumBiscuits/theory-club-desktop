First time opening it

Mac

  • Not sure which Mac you have? Apple menu → About This Mac. If it says Chip: Apple M…, choose Apple silicon. If it says Processor: Intel, choose Intel.
  • Open the .dmg and drag Theory Club into Applications.
  • The first time, right-click the app in Applications, choose Open, then Open again.
  • If macOS says the app is damaged, run xattr -cr "/Applications/Theory Club.app" in Terminal once.

Windows

  • The installer (.exe) is the easy choice. The .msi is for schools and offices that deploy software.
  • If SmartScreen warns about an unknown publisher, choose More info → Run anyway.
  • When you first join a jam room, allow Theory Club through Windows Firewall.

Browser and phone

  • Use it in your browser works on any computer, tablet or phone.
  • On iPhone or iPad, tap Share → Add to Home Screen to install it as an app. On Android, use the browser menu → Install app.
  • The offline file opens in any browser with no internet needed (importing Guitar Pro files still needs a connection).

Installed desktop apps update themselves. Your progress is saved on each device; to move it, open Progress in the app and copy your progress code.
